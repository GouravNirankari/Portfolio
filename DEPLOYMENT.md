# Deployment

## 1. Test locally

Open the folder in VS Code and use Live Server, or open `index.html` directly in a browser.

## 2. GitHub

Create a public repository. For GitHub Pages, a repository named `GouravNirankari.github.io` can be used.

Then run:

```bash
git init
git add .
git commit -m "Initial portfolio"
git branch -M main
git remote add origin https://github.com/GouravNirankari/GouravNirankari.github.io.git
git push -u origin main
```

Enable GitHub Pages from Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

## 3. Contact form

The contact form uses FormSubmit so it can work without JavaScript or a custom backend. On the first submission, FormSubmit may require email activation/verification. If you later want full control, replace the action URL with a service such as Formspree or your own backend.

## 4. Live coding stats

The Codeforces and LeetCode cards are generated by public third-party stat services. They fetch profile data and cache it, so a newly solved problem may take a little time to appear.

## 5. Custom domain

After the site is stable, a custom domain can be connected through GitHub Pages or Vercel. This is optional; the GitHub Pages URL is already public and shareable.
